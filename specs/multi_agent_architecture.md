## 에이전트별 범위

| 에이전트 | 에이전트 설계 v1.1의 담당 | Meta 모델 | 하지 않는 일 |
|---|---|---|---|
| 1. Forensic Visual | 감식-1·2, 가림, 호증 스탬프 | `sam-3.1`, `muse-spark-1.3` | 증거의 진위나 증명력 판단 |
| 2. Fact-Timeline Chronology | 판독, 사실 정리, 문안 작성 | `muse-spark-1.3` | 법적 라벨(예: "채무 승인"), 숫자를 문장에 직접 쓰기(슬롯만 사용) |
| 3. Financial Auditor | 계산, 검증 | 없음 | 청구 가능 여부 판단, 소멸시효 판단 |
| 4. Judicial Form Filler | 편철, 최종 개인정보 검사 | 없음 | 서류 제출 대행 |

## 페르소나(시스템 프롬프트) 원칙

- 역할은 기능으로 적습니다. 예: "당신은 이미지에서 지정된 대상의 위치를 찾아 좌표만 반환합니다. 판단하지 않습니다."
- 자격이나 공직을 내세우는 페르소나("공인 디지털 포렌식 전문가", "20년 경력 법률 연구관", "법원 수석 법원사무관")는 쓰지 않습니다. 도구가 전문가나 법원처럼 보이면 법률 서비스로 오해받을 수 있고, 판단을 내리도록 모델을 유도합니다.
- 금지 명칭과 허용 목록은 `AGENTS.md` 제품 규칙을 따릅니다.
