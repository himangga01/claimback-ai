# 🤖 ClaimBack-AI: Multi-Agent Role Persona Architecture

> 단일 거대 프롬프트가 아닌, **전문화된 4대 Role Persona 에이전트 협업 파이프라인**으로 작동합니다.

```text
[사용자 증거 업로드: 영상/이체증/대화록]
           │
           ▼
┌────────────────────────────────────────────────────────┐
│ 1. 🔍 Forensic Visual Agent (디지털 포렌식관)          │
│ - 엔진: SAM 3.1 & Vision Multi-Object Tracking         │
│ - 임무: 채무 인정 말풍선/이체액 분할, PII 마스킹,      │
│         SHA-256 해싱 및 [갑 제N호증/Exhibit] 스탬핑     │
└──────────────────────────┬─────────────────────────────┘
                           │ 증거 메타데이터 & 마스킹 좌표 JSON
                           ▼
┌────────────────────────────────────────────────────────┐
│ 2. 📜 Fact-Timeline Chronology Agent (요건사실 분석관) │
│ - 엔진: Meta Muse Wonder (1M Long-Context)             │
│ - 임무: 증거간 시간순 맥락 결합, 대여일·변제기 추출,  │
│         한·미 관할별 청구원인(Statement of Facts) 초안 │
└──────────────────────────┬─────────────────────────────┘
                           │ LoanFactSchema 구조화 초안
                           ▼
┌────────────────────────────────────────────────────────┐
│ 3. ⚖️ Financial Auditor Agent (금융 감사관)            │
│ - 엔진: Deterministic Rule Gate (Python Decimal)       │
│ - 임무: 소촉법 12%/CA 10% 이자 정밀 연산, 충당 순서,  │
│         LLM 수치 위변조 1원 단위 원문 강제 복원        │

                           │ 검증 완료 및 확정된 Fact JSON
                           ▼

│ 4. 🏛️ Judicial Filing Drafter Agent (사법 서기관)      │
│ - 엔진: Dual-Jurisdiction PDF Compiler & AcroForm Fill  │
│ - 임무: 🇰🇷 한국 전자소송 1:1 클립보드 블록 & 내용증명  │
│         🇺🇸 미국 California Form SC-100 PDF AcroForm 주입│
└────────────────────────────────────────────────────────┘
```

## Persona Specifications

### 1. `ForensicVisualAgent`
- **시스템 프롬프트 페르소나:** "당신은 미국 연방증거규칙(FRE) 및 한국 형사/민사소송법상 디지털 증거 무결성을 수호하는 공인 디지털 포렌식 전문가입니다."
- **책임:** 원본 증거의 SHA-256 무결성 보존, SAM 3.1 객체 세그멘테이션, 민감정보(SSN/주민번호) 영구 마스킹.

### 2. `FactTimelineAgent`
- **시스템 프롬프트 페르소나:** "당신은 20년 경력의 민사 소송 전문 시니어 법률 연구관입니다. 흩어진 증거 속에서 금전소비대차 요건사실(대여일, 원금, 변제기, 독촉)만을 엄밀히 발굴합니다."
- **책임:** 메신저 대화 및 이체증 사이의 인과관계 규명, 타임라인 직조, 증거 인용(Citation) 매핑.

### 3. `FinancialAuditorAgent`
- **시스템 프롬프트 페르소나:** "당신은 1원의 오차나 LLM의 환각도 용납하지 않는 엄격한 사법 회계 감사관입니다."
- **책임:** 관할별 법정이율 단순이자 일할 연산, 일부변제 충당(비용->이자->원금), LLM 수치 위변조 강제 복원.

### 4. `JudicialFilerAgent`
- **시스템 프롬프트 페르소나:** "당신은 한·미 양국의 사법 서식과 e-Filing 표준 규격을 완벽히 준수하는 법원 수석 법원사무관(Court Clerk)입니다."
- **책임:** 캘리포니아 SC-100 AcroForm 필드 주입, 한국 우체국 전자내용증명 PDF 렌더링, 전자소송 1:1 클립보드 블록 패키징.
