## 1. 프로젝트 개요 및 핵심 가치 (Overview & Value Proposition)

* **해결하려는 문제:** 개인 간 금전 대여, 중고거래·용역 미수금, 소액 투자 사기 등에서 피해 금액이 수백만~수천만 원($1,000~$25,000) 수준일 때, **변호사 선임 비용이 원금보다 커서 법적 구제를 포기하거나 나홀로 소송(Pro Se) 서류 준비에 수십 시간을 쏟아야 하는 사법 접근성 불평등**을 해결합니다.
* **법적·제도적 돌파 전략 (Zero-Cost Pro Se Guardrail):**
  1. **🇰🇷 대한민국 변호사법 제109조 우회:** 일체의 수익 모델(유상성)이 없는 **100% 무료 오픈소스 공익 도구**로 제공하여 변호사법 위반 구성요건을 원천 조각합니다.
  2. **🇺🇸 미국 UPL(비변호사 법률행위 금지) 우회:** 법적 대리인이 아닌 **'당사자 본인의 증거 편철 및 법원 표준 양식 타이핑 보조 도구(Document Preparation & Scrivener Self-Help)'**로 설계하여 미국 각 주 소액재판소(Small Claims Court)의 권장 가이드라인에 완벽히 부합합니다.

## 2. 시스템 아키텍처 및 메타 AI 모델 결합 파이프라인

본선 심사 기준 중 **메타 AI 도구 활용도(25%)**와 **기술적 깊이 및 실행력(20%)**에서 만점을 받기 위해, 단순 텍스트 챗봇이 아닌 **`SAM 3.1` + `Muse Wonder` + `Muse Image` + `결정론적 검증 게이트(Deterministic Rule Gate)`**의 4단계 하이브리드 아키텍처로 구현합니다.

```text
[1단계: 멀티모달 원본 증거 수집 & 무결성 해싱]
  • 입력 데이터: 카톡/iMessage 화면녹화 영상(MP4), 모바일 뱅킹 이체내역 이미지, 수기 차용증 스캔본
  • 무결성 보존: 업로드 즉시 원본 파일별 SHA-256 해시 생성 및 타임스탬프 메타데이터 고정
         │
         ▼
[2단계: SAM 3.1 비주얼 증거 포렌식 & 픽셀 마스킹 엔진 (Visual Evidence Canvas)]
  • 비디오 객체 멀티플렉싱 (최대 16개 동시 추적): 스크롤되는 대화 녹화 영상에서 
    ① 채무 인정 말풍선, ② 송금 완료 금액/날짜 박스, ③ 수기 서명/지장(무인) 영역을 실시간 분할·스틸컷 추출
  • 법원 규격 민감정보 자동 마스킹 (PII Redaction): 제3자 실명, 주민등록번호 뒷자리(SSN), 
    무관한 계좌 거래내역 영역을 픽셀 단위로 정밀 분할하여 검은색 마스킹(Black-out) 처리
  • 자동 호증 스탬핑: 추출된 증거 우측 상단에 [갑 제1호증] / [Exhibit A] 공식 워터마크 합성
         │
         ▼
[3단계: Muse Wonder 법률 추론 & 결정론적 검증 게이트 (Hybrid Verification Gate)]
  • Fact-Timeline 에이전트 (Muse Wonder 1M Context): 파편화된 시각 증거와 대화 로그를 시간순 결합하여
    요건사실(대여일·원금·변제기·독촉일·일부변제액) 구조화 JSON 추출 및 한·영 청구원인(Statement of Facts) 생성
  • 결정론적 검증 게이트 (Python Rule Gate):
    - [수치·고유명사 복원 게이트]: AI가 작성한 청구원인의 금액·날짜·계좌번호가 원본 OCR/추출값과 1원이라도 다르면 즉시 차단 및 원문 복원
    - [요건사실 결손 보류 게이트]: '차용 원금 이체 증빙' 또는 '변제기 도래 근거' 중 하나라도 증거 링크(Citation)가 없으면 자동 생성을 멈추고 '추가 증거 보완 필요(Human Check)'로 분류
  • 판사용 시각 인포그래픽 합성 (Muse Image): 대여~미변제 금전 흐름 타임라인 다이어그램 자동 생성
         │
         ▼
[4단계: 한·미 사법 서류 자동 패키저 (Dual-Jurisdiction Auto-Packager)]
  • 🇰🇷 한국 트랙 (전자소송 브릿지):
    1) 우체국 전자내용증명 표준 PDF 생성
    2) 대한민국 법원 전자소송(지급명령 신청 / 소액사건 소장) 입력칸 1:1 원클릭 복사 UI (당사자 표시·청구취지·청구원인)
    3) 마스킹 완료된 [갑 제1~N호증 통합 PDF] + [증거설명서 표] 원클릭 병합 다운로드
  • 🇺🇸 미국 트랙 (Small Claims e-Filing Ready):
    1) USPS Certified Mail 규격 사전 독촉장(Demand Letter) PDF 생성
    2) 미국 캘리포니아 소액재판소 공식 양식 [Form SC-100] AcroForm PDF 필드 100% 프로그래밍 자동 기입 및 출력
```

## 3. 핵심 모듈별 상세 구현 명세 (Module Specifications)

### 모듈 1: `SAM 3.1` 기반 인터랙티브 비주얼 포렌식 캔버스 (`frontend/src/components/ForensicCanvas.tsx`)
* **핵심 역할:** 정적 이미지뿐만 아니라 스크롤 화면 녹화 비디오(MP4)에서 핵심 증거 객체와 가려야 할 개인정보 객체를 동시에 분할(Segmentation)하고 시각적으로 조작하는 UI.
* **구현 기능:**
  * **초록색 마스크 (Evidence Highlight):** 채무 인정 발언(`"다음 달까지 꼭 갚을게"`), 송금 내역(`"5,000,000원"`), 차용증 도장/서명 영역 분할 및 스틸컷 캡처.
  * **검은색 마스크 (Privacy Redaction):** 한국 민사소송규칙 및 미국 연방민사소송규칙(FRCP Rule 5.2)에 의거해 주민번호 뒷자리, SSN, 타인 계좌번호를 클릭 한 번으로 영구 마스킹.
  * **호증 배지 자동 오버레이:** HTML5 Canvas 위에서 분할된 증거 이미지에 빨간색 테두리와 `갑 제1호증 (금전소비대차 송금내역)` / `Exhibit A (Wire Transfer Receipt)` 스탬프를 렌더링.

### 모듈 2: `Muse Wonder` + 결정론적 규칙 검증 엔진 (`backend/app/services/reasoning_gate.py`)
* **핵심 역할:** `Muse Wonder`의 다국어 장문 추론 능력과 파이썬 기반의 엄격한 규칙 검사기(Rule Validator)를 결합하여 법률 문서의 할루시네이션을 '0%'로 통제.
* **구현 기능:**
  * **이자 및 소멸시효 계산기 (Deterministic Calculator):** LLM의 확률적 암산에 의존하지 않고, 파이썬 `Decimal` 모듈로 원금, 일부 변제 충당 순서(비용 $\rightarrow$ 이자 $\rightarrow$ 원본), 한국 소송촉진법상 연 $12\%$ 지연손해금 및 미국 캘리포니아주 연 $10\%$ 법정이자를 $1$원/$1$센트 오차 없이 정밀 계산.
  * **근거 연결 강제 (Citation Enforcement):** 청구원인 본문의 모든 문장은 반드시 `[갑 제1호증, SHA256: a3f9...]` 형태의 원본 증거 ID를 참조해야만 최종 서류로 병합되도록 강제.

### 모듈 3: 한·미 양국 공식 법원 서류 컴파일러 (`backend/app/services/document_packager.py`)
* **핵심 역할:** 전자소송 보안 모듈에 막히지 않고 실제 법원에 즉시 제출 가능한 완성본 파일을 생성.
* **구현 기능:**
  * **미국 `Form SC-100` 자동 기입기:** 파이썬 `pypdf` 라이브러리를 사용해 캘리포니아 법원 공식 `sc100.pdf` 양식의 내부 AcroForm 필드(`PlaintiffName`, `DefendantName`, `ClaimAmount`, `WhyDefendantOwesMoney`, `DateDemandMade` 등)에 추출된 영문 데이터를 직접 주입하여 즉시 인쇄·e-Filing 가능한 PDF 반환.
  * **한국 전자소송 1:1 매핑 브릿지 & 호증 편철기:** `ReportLab`과 `PyMuPDF`를 사용하여 ① 내용증명서, ② 전자소송 포털(`ecourt.scourt.go.kr`) 입력창 구조와 동일한 클립보드 복사 블록(청구취지/청구원인), ③ 표지(증거설명서)와 마스킹된 갑 호증들이 순서대로 묶인 단일 PDF 패킷 생성.

## 4. 기술 스택 및 디렉토리 구조 (Tech Stack & Directory Structure)

### 기술 스택
* **Frontend:** React 19, TypeScript, Vite (또는 Next.js), Tailwind CSS, Lucide Icons, HTML5 Canvas API
* **Backend:** Python 3.11+, FastAPI, Pydantic v2 (구조화된 JSON 스키마 강제)
* **AI & Vision API:** Meta Model API (`Muse Wonder`, `Muse Image`, `SAM 3.1`)
* **Document & Crypto:** `pypdf` (SC-100 AcroForm 매핑), `PyMuPDF` / `ReportLab` (호증 스탬핑 및 PDF 병합), `hashlib` (SHA-256 증거 무결성 해싱)
* **Testing & Quality:** `pytest` (백엔드 판정·계산·복원 게이트 단위 테스트), `Playwright` (E2E 데모 시나리오 검증)

## 5. 단계별 스프린트 일정 및 TDD 체크리스트 (Execution Roadmap)

해커톤 본선 일정에 맞춘 4단계 실행 계획입니다.

### Phase 1: 스펙 확정 및 결정론적 코어 엔진 + TDD 구축
* [ ] 금전소비대차 요건사실 JSON 스키마 정의 (`LoanFactSchema`: 채권자, 채무자, 원금, 대여일, 변제기, 일부변제 내역, 독촉 여부, 원본 호증 해시)
* [ ] 파이썬 결정론적 검증 게이트(`verification_gate.py`) 구현 및 **단위 테스트 50개 이상 작성 먼저 통과** (원금·날짜 변조 시 원문 강제 복원, 근거 없는 주장 보류 처리, 한·미 법정이자 계산 정확도 검증)

### Phase 2: `SAM 3.1` 비주얼 포렌식 & `Muse` 멀티모달 파이프라인 연동
* [ ] 시연용 표준 샘플 데이터셋 제작 (카톡/iMessage 대화 스크롤 영상 1건, 토스/Zelle 이체 캡처 2건, 수기 차용증 이미지 1건)
* [ ] `SAM 3.1` API 연동: 업로드된 영상/이미지에서 '채무 인정 말풍선', '이체 금액', '서명/도장' 마스크(초록색)와 '주민번호/계좌번호 뒷자리' 마스크(검은색) 동시 분할 파이프라인 연결
* [ ] `Muse Wonder` API 연동: 분할된 증거 텍스트와 타임스탬프를 결합해 한국어(지급명령 청구원인)와 영어(SC-100 Statement of Facts) 동시 생성
* [ ] `Muse Image` API 연동: 사건 요약 금전 흐름 타임라인 다이어그램 생성

### Phase 3: 한·미 법원 공식 양식 컴파일러 및 3분할 프론트엔드 UI 완성
* [ ] **미국 트랙:** `pypdf`로 캘리포니아 `Form SC-100` 공식 PDF 양식 자동 기입 모듈 완성 및 출력 확인
* [ ] **한국 트랙:** 우체국 내용증명 PDF, 전자소송 1:1 클립보드 복사 패널, `[갑 제1~3호증 + 증거설명서]` 통합 PDF 병합 모듈 완성
* [ ] **3분할 대시보드 UI 구현:** `[좌측: 증거 리스트 & SHA-256 검증 상태]` + `[중앙: SAM 3.1 실시간 마스킹 & 호증 스탬핑 캔버스]` + `[우측: 🇰🇷 한국 전자소송 / 🇺🇸 미국 SC-100 실시간 전환 프리뷰어]`

### Phase 4: E2E 안정화 및 2분 데모 영상 촬영 (Demo Polish)
* [ ] API 네트워크 지연(Latency) 대비용 캐싱 및 폴백(Fallback) 스냅샷 안전장치 적용 (라이브 시연 중 끊김 원천 방지)
* [ ] 2분 피칭 영상 녹화 및 GitHub 저장소 문서화 마무리
